- 2026-09-01: HV Breaker Simulator — Implemented `pkg/breaker`, an in-memory HV circuit breaker + protection relay simulator per `tmp/hvcbagentprompt.md`: SCADA-facing interfaces (position, analog, protection/autoreclose configuration, select-before-operate control, status, event subscription), IEC 60255 inverse-time and instantaneous overcurrent protection, an ANSI-79 autoreclose state machine, and a single-goroutine `Simulator` tying it together. While blocked, `Select` and `Operate` are rejected with `*InterlockError`; a selection made before blocking survives it and can still be Operated after Unblock. Added `EventControlBlocked`/`EventControlUnblocked` events.
